## Formal definition

La regresion lineal multiple modela una variable dependiente como combinacion lineal de varias variables independientes.

## Intuition

Una propiedad fisica puede depender simultaneamente de temperatura y presion, y un modelo lineal multiple ayuda a estimar el peso relativo de cada factor.

## Why it matters

Este bloque sirve para modelar datos experimentales, resumir tendencias y hacer predicciones utiles.
