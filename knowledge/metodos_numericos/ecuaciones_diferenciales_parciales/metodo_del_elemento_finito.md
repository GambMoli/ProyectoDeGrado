## Learning goal

Entender metodo del elemento finito y reconocer cuando conviene usarlo dentro del bloque de ecuaciones diferenciales parciales.

## Formal definition

El metodo del elemento finito divide el dominio en elementos pequenos y construye una aproximacion global a partir de funciones locales ensambladas.

## Intuition

En geometria compleja, en lugar de usar una malla rectangular simple, el elemento finito adapta el dominio a triangulos o elementos mas flexibles.

## Why it matters

Este bloque aproxima fenomenos distribuidos como calor, potencial y difusion en una o mas dimensiones.
