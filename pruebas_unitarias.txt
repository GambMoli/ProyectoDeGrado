================================================================================
  ====Script Test====
  Archivo: run_tests.ps1
================================================================================

Proposito:
  Automatiza la ejecucion de todas las pruebas unitarias del proyecto.
  Ejecuta el backend con pytest y el frontend con vitest (pnpm).
  Clasifica las pruebas en tres categorias: Casos Normales, Casos Limite,
  Casos Erroneos.

Archivos de prueba Backend:
  - tests/test_security.py
  - tests/test_expression_normalizer.py
  - tests/test_llm_text.py
  - tests/test_math_parser_functions.py
  - tests/test_extract_student_answer.py
  - tests/test_math_answer_functions.py
  - tests/test_practice_state.py

Filtros pytest por categoria:
  - Casos Normales  → -k TestNormal
  - Casos Limite    → -k TestLimite
  - Casos Erroneos  → -k TestError

Scripts frontend (pnpm):
  - Casos Normales  → test:normal   (vitest -t "casos normales")
  - Casos Limite    → test:limite   (vitest -t "casos limite")
  - Casos Erroneos  → test:error    (vitest -t "caso erroneo")

Ejecucion:
  .\run_tests.ps1
  powershell -ExecutionPolicy Bypass -File .\run_tests.ps1

Codigo de salida:
  0 → todas las pruebas pasaron
  1 → al menos una prueba fallo
